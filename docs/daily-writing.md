# 한 줄 기록

1. 블로그 하단의 Write 선택
2. 한 줄 남기기 선택
3. 오늘 배운 핵심과 날짜 입력
4. 필요하면 내 블로그 원문 선택 또는 외부 출처 주소 입력
5. 발행

내 블로그 원문과 외부 출처는 함께 연결할 수 있다. 외부 출처 제목을 비워두면 도메인으로 표시된다. 원문을 삭제하면 홈에서는 해당 링크를 표시하지 않는다.

기록 하나가 선 하나다. 같은 날 네 개를 쓰면 선 네 개가 쌓인다. Collected는 전체 기록 수이고 각 월의 숫자는 그달의 기록 수다. 선에 마우스를 올리면 미리보기, 클릭하거나 키보드로 선택하면 고정된다. 이전 기록은 월 이동 버튼이나 모바일 좌우 스와이프로 확인할 수 있다.

실제 기록이 없으면 0으로 시작한다. design 폴더의 시안 데이터는 실제 블로그에 포함되지 않는다.

현재 저장 방식은 기존 GitHub 기반 편집기다. 온라인에서 발행하면 저장소에 기록되고 GitHub Pages 배포가 끝난 뒤 사이트에 반영된다. 즉시 서버 저장형 편집기로 전환한 것은 아니다. 로컬에서는 기존 글쓰기 서버를 함께 실행해야 저장할 수 있다.

내 블로그 원문 선택지는 배포 시 갱신된다. 새 글을 발행한 뒤 배포 완료 후 작성 화면을 새로고침하면 새 글도 선택할 수 있다.

개발 검증: `node --test tests/daily.test.mjs`, `npm run build`
